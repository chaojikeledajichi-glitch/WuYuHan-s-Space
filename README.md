# 一方小天地 · 个人洞洞板

2026-10-02 当前编辑流程：分类仅编辑名称，浏览页不显示分类介绍；作品仅编辑名称、所属分类和封面。保留封面上传，移除 PDF/详情长图的网页上传与移除入口。作品详情由用户在聊天中提供文件后预先处理、上传，现有 PDF 与图片数据继续保留。下文的 PDF 上传说明为此前实现记录，当前编辑界面不提供该入口。

独立静态网站，以参考视频中的米白洞洞板、金属挂件、作品夹、证件卡和航空信封为设计方向。

## 本地查看

在本目录运行 `npm install`，然后运行 `node server.cjs`，打开 http://127.0.0.1:4317 。本地预览使用 `.sites-runtime/content.sqlite`，与线上数据库分离。

## 换成自己的资料

登录网站后，点击顶部“编辑内容”。可以修改网站名称、首页文案、姓名、介绍、邮箱、作品、过往经历和日常。作品最多 12 件，过往经历最多 16 条，日常最多 30 条。

作品集按“三个分类 → 分类内项目 → 项目详情”浏览，详情可返回所属分类或全部分类。默认分类为品牌与视觉、数字体验、自由创作；在“编辑内容 → 作品”中可修改三个分类的名称与介绍，并为每个项目选择所属分类。洞洞板作品夹展示三个分类与项目数量。已有项目根据原封面颜色初始归类，标题、正文等内容保留。分类保存于 `projectCategories`，项目通过 `categoryId` 关联；旧编辑窗口不传新字段时会保留已保存的分类和项目归属。

`shared/portfolio.mjs` 提供前后端共用的分类默认值与旧内容兼容处理，构建时生成浏览器脚本 `dist/portfolio.js` 并内嵌到 Worker 中。

黑色挂牌、左侧导航与物件索引中的“过往经历”打开经历列表。每段经历可填写名称、时间、学校或单位、专业或职位及介绍，按编辑顺序展示。首次使用为空，不将旧技能内容当作个人履历。经历保存在原有内容记录的 `experiences` 数组中；已有 `skills` 数据保留，旧编辑窗口保存时不会清空新经历，无需修改数据库表结构。

“预览效果”暂时将草稿应用到当前页面；“保存到网站”写入线上 D1 数据库，并自动移除“内容示例”标记。保存失败时保留当前草稿，重新打开编辑器可继续；刷新或离开前有未保存提醒，也可以下载 JSON 草稿备份。多窗口编辑使用版本检查，旧草稿不能直接覆盖新内容。

编辑权限在服务端校验：先验证平台转发的当前站点用户 ID 与所有者邮箱，首次保存后同时绑定稳定的站点用户 ID。网站分享权限仍由 Sites 管理。本地预览只监听回环地址并模拟所有者，不能作为公开托管服务器。

`dist/content.js` 仅作为首次未保存时的默认内容。保存后的内容以数据库为准。

## 交互

“关于我”详情中尚未上传照片时，仅所有者看到添加入口；上传后自动保存，详情页仅展示照片，不显示“替换照片”按钮。替换、预览或移除照片可在编辑面板操作。支持 5 MB 以内的 JPG、PNG、WebP，照片保存到 R2，同时保留现有个人介绍。

桌面鼠标悬浮时，固定底板、孔洞和顶部安装钉保持不动；完整物件（包括透明外框、活动挂环、纸面和文字）绕顶部挂点轻摆，带有随鼠标变化的反光与阴影，移开后通过阻尼弹簧自然回落。点击区域保持固定，避免物件移动造成悬浮闪断。手机触摸保持静态并可直接点击。默认尊重系统“减少动态效果”设置；页脚“物件动效”开关可显式开启或关闭，并保留本机偏好。

`dist/motion.js` 管理分层、弹簧与输入；`dist/motion.css` 管理反光和阴影。干净底板使用 `dist/assets/pegboard-clean.png`，各物件通过 `dist/assets/masks/*.svg` 遮罩显示原图对应区域，透明外框中不包含会跟着移动的孔洞。遮罩只控制原照片的显示区域，不绘制替代物件。两张图片和全部遮罩解码成功后才切换到分层画面，加载失败时保留原完整照片和详情入口。

六个物件可点击打开详情，作品可进一步查看；Esc、关闭按钮或点击遮罩关闭。物件索引提供另一种浏览入口。支持键盘操作和减少动态效果偏好。夜间灯光偏好仅保存到当前浏览器。手机上可左右滑动洞洞板。

## 结构

- dist/index.html：页面与物件入口
- dist/styles.css：布局、字体、响应式与灯光
- dist/content.js：可替换的个人内容
- dist/app.js：详情、作品、索引与主题交互
- dist/assets/pegboard.png：原创生成的洞洞板视觉素材

新增 `dist/editor.js`、`dist/editor.css` 提供编辑界面；`server/worker.mjs` 提供服务端读取、校验和保存；`db/schema.ts` 与 `drizzle` 管理数据库迁移。

构建：`npm run build`，输出 `dist/server/index.js` 与托管元数据。Worker 内嵌前端资源，运行时无需第三方依赖。测试：`node --test tests/api.test.cjs`。不要修改已经上线的迁移，新增字段时生成新迁移。

## 项目封面与详情

编辑内容 → 作品中，项目封面和详情 PDF 分别上传并保存。封面支持 5 MB 以内 JPG、PNG、WebP，详情支持 30 MB 以内、最多 1000 页的未加密 PDF。替换或移除一个文件不会影响另一个。项目列表展示独立封面，项目详情只展示上传的 PDF。PDF 按页面顺序连续滚动，超长单页分段渲染，只保留阅读位置附近的画布，避免长文件占用大量显存。旧文字资料保留在数据中，旧 PDF 封面保留作为初始封面，可独立替换。

PDF 媒体接口提供文件长度、HEAD 和单段字节范围（206）响应。阅读器按需读取文件，优先渲染首屏；仅解析阅读位置附近的页面，文字提取不阻塞显示。加载时显示进度，文件不存在、加载失败或长时间等待时提供提示和重新加载入口。大文件首屏速度仍取决于 PDF 内部结构、页面复杂度与网络。接口回归检查：`node --test --test-isolation=none tests/api.test.cjs tests/pdf-range.test.cjs`。

阅读器使用 PDF.js 官方兼容构建，主线程与 Worker 保持同一版本。`dist/pdf-transport.mjs` 优先请求 256 KiB 首段，并通过 `PDFDataRangeTransport` 按需读取后续数据。媒体接口的 `pdfRange=start-end` 参数与 HTTP Range 共用校验和存储读取，适用于中间代理未转发 Range 头的环境；不再先发起整文件请求再取消。读取具有超时、登录状态、数据完整性校验和重试提示。详情在独立阅读框中连续滚动，关闭或返回时取消请求。回归检查：`node --test --test-isolation=none tests/api.test.cjs tests/pdf-range.test.cjs tests/pdf-transport.test.cjs`。

项目详情现在直接连续显示内容，只保留关闭按钮，移除标题、分类导航、原文件按钮、嵌入阅读框和页间间距。PDF 首屏先完成显示，再加载附近页面，显示宽度限制为 1200 像素以减少渲染量。

“编辑内容 → 作品 → 详情长图”支持 WebP、JPG、PNG 多图上传，每张最大 5 MB，一次最多 40 张、合计 50 MB；按照文件名的自然顺序排列。上传时将大图缩至最多 1600 像素宽，按最多 2400 像素高分段并编码 WebP（质量 90%），合适尺寸的 WebP 保留原文件。每个项目最多保存 120 段，首段立即加载，后续按需加载；有图片时优先展示图片，原 PDF 保留。替换 PDF 会清除旧详情图片以避免混用。详情图片通过已有私有媒体接口保存，服务端校验 URL、尺寸与所有者；旧编辑器不传新字段时保留图片。

PDF 上传现在自动生成快速预览：在上传时按最多 1600 像素宽、2400 像素高转为 WebP 段，保存原 PDF 与全部预览后才更新草稿。保存到网站后，项目直接显示图片，不再在每次打开时解析 PDF。快速预览最多 120 段，超出时提示拆分项目；转换或上传失败不会替换已有详情。图片仍需首次下载，但浏览器可缓存已下载的图片。
